## 🌟 المميزات الرئيسية (Key Features)

### 🎨 1. ثلاث محركات عرض بصرية (Tri-Engine Display)
* **MORPHOS ∞ Engine:** أرقام حية مرسومة بمعادلات منحنيات بيزيير (Cubic Bézier Splines) وفيزياء الزنبرك المرنة على Canvas 60FPS.
* **3D Split-Flap Clock:** ساعة قلاّبة كلاسيكية ثلاثية الأبعاد مع ظلال واقعيه وصوت تكتكة ميكانيكية اختياري.
* **Precision Digital:** شاشة رقمية نقية بـ 4 خطوط احترافية و 3 أنماط (Pure, Glass, Ambient Neon).

### ⏱️ 2. خمسة أوضاع متكاملة (5-in-1 Time Studio)
* **Clock:** ساعة مكتب كاملة (12/24 ساعة) مع التاريخ واليوم.
* **Timer:** مؤقت سريع مع 16 إعداد جاهز (Presets) وإمكانية تخصيص الوقت.
* **Study (Pomodoro):** نظام مذاكرة وعمل متكامل مع تقسيم الجلسات، قائمة مهام (To-Do List)، وإحصائيات إنجاز يومية وشهرية مع تصدير `CSV`.
* **Stopwatch:** ساعة إيقاف عالية الدقة (Centiseconds) مع جدول تسجيل اللفات (Laps).
* **Countdown:** عد تنازلي للأحداث المهمة بالأيام والساعات والدقائق.

### ⚡ 3. تقنيات متقدمة (Power Features)
* **18 Curated Themes:** تشمل *OLED Void, Dark Studio, Cyberpunk, Royal Gold, Matrix, Nord Frost* وغيرها.
* **Triple-Layer Keep-Awake:** تقنية منع انطفاء الشاشة (مخصصة للتابلت والموبايل مثل Samsung Tab A9+ و Chrome).
* **Web Audio Synthesizer:** مؤثرات صوتية مدمجة بالكود بدون أي ملفات صوت خارجية.
* **Auto-Hide Idle UI:** اختفاء تلقائي للأزرار بعد 3 ثوانٍ من عدم الحركة لتركيز كامل.

## ⌨️ اختصارات لوحة المفاتيح (Hotkeys)

| الزر | الوظيفة |
| :--- | :--- |
| `Space` | تشغيل / إيقاف المؤقت أو البومودورو أو ساعة الإيقاف |
| `D` | التبديل السريع بين المحركات الثلاثة (`Morphos ∞` ↔ `Flip 3D` ↔ `Digital`) |
| `F` أو `Double Click` | تفعيل / إنهاء وضع ملء الشاشة (Fullscreen) |
| `Esc` | إغلاق النوافذ والقوائم المفتوحة |
